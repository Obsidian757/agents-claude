## Onboarding checklist for new AI users
- [ ] **Define your goal and scope**: Write down what you want the AI to help with and the boundaries (e.g., topics to avoid, tone, audience).  
- [ ] **Choose a safe workspace**: Use a non-production environment or a sandbox for experiments and keep sensitive data out of prompts.  
- [ ] **Prepare sample inputs**: Collect a few representative examples (good, bad, edge cases) to calibrate responses.  
- [ ] **Draft prompt guidelines**: Note the desired style, length, format, and constraints (e.g., cite sources, no speculation).  
- [ ] **Set quality criteria**: Define how you will judge responses (accuracy, clarity, bias, tone, completeness).  
- [ ] **Create a feedback loop**: Decide how you’ll review, edit, and iterate on outputs before using them.  
- [ ] **Establish data hygiene**: Remove PII, redact secrets, and confirm data-sharing policies.  
- [ ] **Record versioning**: Track prompts, settings, and model versions for repeatability.  
- [ ] **Document limitations**: Note known model gaps or areas requiring human verification.  
- [ ] **Plan escalation paths**: Identify when to ask a subject-matter expert or switch tools.
